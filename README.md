# 📄 Dynamic Resume Builder

A modern, interactive, and fully dynamic web application built using HTML5, CSS3, and TypeScript. This tool allows users to input their professional details in real-time and instantly generates a clean, beautifully formatted resume.

## ✨ Features

* **Dynamic Form Synchronization:** Seamlessly captures user inputs (Personal Info, Education, Experience, and Skills) and updates the resume preview instantly.
* **TypeScript Logic Engine:** Engineered with strict TypeScript to handle DOM manipulation, form validation, and state management safely.
* **Sleek & Professional UI:** Styled with a clean, modern aesthetic using CSS3 to ensure the final output looks corporate and print-ready.

---

## 🛠️ Tech Stack

* **Frontend Structure:** HTML5
* **Styling & Layout:** CSS3
* **Core Logic Engine:** TypeScript (Strict Typing & Event Handling)
* **Hosting Platform:** Vercel
